# 💼 Gestor de Orçamentos para Freelancers

> Sistema web que ajuda freelancers a criar, enviar e acompanhar orçamentos profissionais em minutos — sem depender de Word ou planilhas.

![Status](https://img.shields.io/badge/status-em%20planejamento-yellow)
![Licença](https://img.shields.io/badge/licen%C3%A7a-MIT-blue)

---

## 🎯 O Problema

Freelancers (designers, marceneiros, eletricistas, fotógrafos, desenvolvedores) perdem tempo montando orçamentos manualmente, não têm histórico organizado e frequentemente esquecem de cobrar ou acompanhar propostas enviadas.

## 💡 A Solução

Um sistema simples onde o freelancer:
- Cadastra seus serviços com preços
- Gera orçamentos em PDF com sua marca
- Envia por link ou WhatsApp
- Acompanha status (enviado / aprovado / pago)

## 🚀 Funcionalidades Planejadas

- [ ] Cadastro de clientes
- [ ] Catálogo de serviços com valores
- [ ] Criação de orçamento em poucos cliques
- [ ] Exportação em PDF personalizado
- [ ] Link público para o cliente aprovar
- [ ] Controle de status (enviado, aprovado, recusado, pago)
- [ ] Lembretes automáticos
- [ ] Relatório mensal de propostas e faturamento

## 🛠️ Stack Prevista

- *Backend:* Python (FastAPI)
- *Banco:* SQLite (MVP) → PostgreSQL (produção)
- *Frontend:* HTML + HTMX ou React
- *PDF:* ReportLab ou WeasyPrint
- *Deploy:* Railway / Render
